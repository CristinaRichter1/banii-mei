Pentru a scrie ai nevoie de un cont GitHub. Mesajele și răspunsurile sunt publice, nu mesaje private.

**Nu publica extrase, facturi, polițe, IBAN-uri, CNP-uri, parole, copii ale bazei de date sau jurnale complete.** Ascunde datele personale și financiare din capturi înainte de publicare.

Când raportezi o problemă, include versiunea aplicației, pașii urmați, rezultatul așteptat și ce s-a întâmplat efectiv.

Acest proiect este destinat comunicării cu utilizatorii. Codul aplicației și datele financiare nu sunt publicate aici.
