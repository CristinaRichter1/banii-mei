Prima instalare

Configurarea te conduce pas cu pas.

Descarcă versiunea beta pentru Windows x64 numai de pe pagina release-ului. Este un pachet de test, încă nesemnat digital; Windows poate afișa un avertisment privind editorul necunoscut.

  1. Deschide configuratorul

    Dezarhivează pachetul descărcat, citește instrucțiunile incluse și deschide „Instaleaza Banii mei.exe”. Alege „Instalează sau actualizează”, apoi „Prima instalare”.

  2. Pregătește stocarea datelor

    Dacă lipsește SQL Server, configuratorul oferă instalarea gratuită SQL Server Express. Citește și acceptă termenii Microsoft dacă ești de acord, apoi apasă „Instalează automat”. Windows poate cere confirmarea ta. Dacă există deja SQL Server, se verifică instalarea existentă.

  3. Confirmă instalarea aplicației

    Verifică rezumatul și așteaptă finalizarea. Nu deschide „Banii mei” înainte de terminarea instalării. Dacă se cere repornirea calculatorului, urmează indicația afișată.

  4. Pregătește primul plan în „Banii mei”

    La prima deschidere, completează configurarea inițială: salutul opțional, luna de început, veniturile estimate și luna pe care o finanțează salariul. Datele se salvează când confirmi.

Mut datele de pe alt calculator. Aleg tot „Prima instalare”?

Nu. Alege „Restaurare dintr-o copie de rezervă” și folosește copia creată cu „Banii mei”. Păstrează originalul până când ai verificat datele restaurate. O copie protejată necesită parola ei.

Trebuie să conectez Gmail sau Calendar?

Nu pentru configurarea inițială. Integrările se configurează separat, dacă vrei să le folosești.

Ce fac dacă instalarea se oprește cu o eroare?

Nu șterge date sau baze existente pentru a reîncerca. Notează mesajul, versiunea și pasul la care a apărut problema, apoi cere ajutor. Nu publica jurnale complete sau date personale.
